## Implementation
- Restore M13 unverified-provider guard before platform secure-storage access; no reviewed-provider override in production.
- Authenticated capabilities, issuance/revocation, reconcile, paginated outcome sync; matching canonical PHP digests and signed recipient receipt. Historical outcome alone cannot acknowledge an outbox: fresh M13 publication check required.
- Durable encrypted checkpoint after verification of a peer, before any source packet is disclosed. No receipt is needed to recover an interrupted attempt via HTTPS. Preserve the exact client ID and source bytes. Only current session's fresh packets or matching checkpoints may be retried offline; no new lease is substituted for a possibly delivered packet. Source-authoritative recovery after process restart and expiry. Roster mismatch, invalid proof and immutable-byte mismatch fail closed.
- Native discovery plus bounded authenticated local TCP; stop on foreground lifecycle, route exit, expiry or changed authenticated policy/key/roster. No background mesh or plaintext alternative. Existing conversation action sheet, popup, chat and composer reused; no visual redesign.
- Build workflow compiles Rust Android arm64-v8a, armeabi-v7a, x86_64 and iOS device/simulator archives, checks APK native entries and iOS ABI symbols. Linux tests use actual native provider. Previous messaging regression suite expanded; recovery tests cover optional receipt, pagination, same-ID source, expiry, rejection and tampering.

## Limits and acceptance
Same-LAN/hotspot IPv4 only; both peers explicitly opt in online before offline exchange. No Bluetooth-only, Wi-Fi Direct group negotiation, mesh, background delivery, SOS, location, media or Circle relaying. These are not certified by the available original documents (original Relay PRD/TRD pages unavailable). Server and reviewed M13 gates remain disabled pending independent review. A first-time local-network OS prompt can interrupt activation; re-enable after permission grant. Offline revocation cannot be observed until connectivity returns or the bounded lease expires. Recipient offline decryption preview is noncanonical, current-session only; authoritative mailbox maps exact bytes on reconnect. Retention, crash atomicity and local proof privacy need independent review, including exhaustion of the bounded decryption bridge when the sender never publishes. Do not call an APK compile a native-linked build or physical-device interoperability.

Physical matrix before release: Android/Android, iOS/iOS, Android/iOS on isolated Wi-Fi/hotspot with WAN disabled; consent, permission refusal, peer absent, wrong key, interrupted frame, lost receipt, kill/relaunch, expiry, account switch, reconnect, duplicate source, changed roster, server gate disabled, previous messaging and UI. Use isolated test environment; do not enable production.
