No actual store payments in CI.
- Secure owner-scoped journal stores request UUID/context/binding/phase, never raw purchase proof. Lost context response reuses request ID; uncertain launch recovers through store instead of charging again. Restore can clear expired unmatched context only after successful store query. Pending or failed verification never finishes a receipt; owner fencing before and after every await, explicit identity access-token owner tag and no cross-account automatic auth retry. Stable request UUID derived from proof/context and owner. Native store holds recoverable receipt. Logout leaves journal account-isolated to permit same-owner recovery; no entitlement cache. Subscription screen refreshes on foreground and once per minute, receipt recovery on open/resume/update/restore. Backend scheduled reconciliation authoritative when app not open.
